# Security policy

This repository holds data, not code: weekly copies of the signed checkpoints of the Sigelith
public log. If you find a problem with the log itself — a checkpoint that does not verify, two
checkpoints with the same number, a signature by an unexpected key — or with sigelith.org,
please report it privately by e-mail to **kontakt@advena-partners.com** (English, German or
Polish), as listed in <https://sigelith.org/.well-known/security.txt>.

Please do not open a public issue for a vulnerability. A checkpoint that fails verification is
evidence, not a secret: attach the file and the result of your check.
